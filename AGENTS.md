# Rules for this website

This folder is Vieno W. Wu's personal website, published at https://venla9402.github.io.
Any agent working here (Claude Code, Codex, …) follows these rules.

## Never publish
- Phone number, home address, or a personal (non-school) email
- Grades, salary, visa status, date of birth
- Anything in `private/`: it must be listed in `.gitignore` before the first commit
- Anything not on the CV or approved by Vieno (no invented achievements, numbers or quotes)

## Ask me first
- Before any `git push`, creating a repository, or any change on GitHub
- Before deleting or overwriting a file
- Before adding a new page, a new section, or any third-party script, tracker or analytics
- Before publishing contact details other than the Columbia email, LinkedIn and GitHub

## Style
- Plain HTML and CSS (a few lines of JavaScript only when needed), no build tools or frameworks
- Vibe: professional but casual; clean and minimal, plenty of white space
- Colors: Columbia blue (`#B9D9EB`) with a deep navy (`#0B2D5B`) for text and accents
- Navigation: streamlined, with one sticky top bar linking to each section
- Keep the CV's section order: Education, Experience, Projects, Technical Skills
- Works on phones; images have alt text; links to other sites open in a new tab
- Portfolio, if added: a gallery page that links to each project

## When you finish
- Tell me what you changed and what you skipped, and list every file you created or edited
